# CollapseLab

CollapseLab is a production failure-mechanics laboratory for reproducible experiments on overload, recovery, measurement validity, and emergent failure loops.

The first milestone is **CF-001 — Coordinated Omission**: proving, with revision-bound evidence, how a closed workload can hide a deterministic service stall while an open arrival workload exposes the tail.

> Status: early experimental development. Implementation work is isolated on feature branches until its verification gates pass.
